# 🎥 Text to Video Generation

This project generates short videos from text prompts using a diffusion-based
text-to-video generative model.

## ✨ Features
- Converts text prompts into short videos
- Uses pre-trained text-to-video generation models
- Demonstrates multimodal Generative AI
- Notebook-based implementation

## 🛠 Technologies Used
- Python
- Hugging Face Inference API
- Wan 2.2 Text-to-Video Model
- Diffusion-based Video Generation
- PyTorch
- Hugging Face Hub
- Jupyter Notebook

## 🔐 API Key Setup

This project uses the Hugging Face Inference API.

Set your Hugging Face token as an environment variable:

### Linux / Mac
export HF_TOKEN=your_huggingface_token

### Windows
set HF_TOKEN=your_huggingface_token

▶ How to Run

Install dependencies
pip install -r requirements.txt

Open and run the notebook:

`Text_to_video.ipynb`

📌 Example

Prompt: "A wide cinematic shot of a calm ocean under a massive full moon, moonlight shimmering across gentle waves, thin clouds slowly drifting past the moon, cool blue color palette, static camera with natural motion only, peaceful nighttime atmosphere"

Output: AI-generated video
