# 🚀 Gen-AI

This repository contains **Generative AI projects** covering NLP, Large Language Models (LLMs), chatbots, and Retrieval-Augmented Generation (RAG).  
All projects are beginner-friendly and focused on practical implementation.

---

## 🔹 Projects

### 1️⃣ LLaMA-3 AI Chatbot with Web Search
- Conversational AI chatbot using **Meta LLaMA-3-70B Instruct**
- Built with **Hugging Face Inference API**
- Supports conversation memory
- Integrates **live web search**
- Gradio-based interactive UI

📂 Folder: `01-llama3-chatbot`

---

## 🛠 Technologies Used
- Python
- Hugging Face Inference API
- LLaMA-3
- NLP & LLM concepts
- RAG (upcoming)
- Gradio

---

### 2️⃣ Text to Image Generation
- Generates images from text prompts using diffusion models

- Notebook-based implementation

📂 Folder: `02-text-to-image`

---

## 🛠 Technologies Used
