# 🔊 Text to Speech Generation

This project converts text input into natural-sounding speech using a pre-trained
Text-to-Speech (TTS) model.

## ✨ Features
- Converts text into spoken audio
- Uses a pre-trained Text-to-Speech model
- Generates audio output files
- Notebook-based implementation

## 🛠 Technologies Used
- Python
- Text-to-Speech (TTS) Models
- Hugging Face Transformers / TTS libraries
- PyTorch
- Audio Processing
- Jupyter Notebook

## ▶ How to Run
1. Install dependencies  

2. Open and run the notebook  
`Text_to_speech.ipynb`

## 📌 Example
Input: *"Hello, how are you?"*  
Output: AI-generated speech audio file
